# E-Commerce-html-css-js
A simple E-Commerce website built using HTML, CSS, and JavaScript. Perfect for students and beginners to learn frontend development.

This index.html file contains all html css and javascript in one html document for a cleaned version to avoid unwanted stack.

# PROCESS
1.Download the file from the repository.

2.Go to your file explorer and open the index.html file
